# AS3K R11 — Impresión nativa/PDF CLOSED/PASS (2026-11-09)

Único AS3K-DIAG ./alphasma3k, rama as3k-mame0289-dev. Se añadió
la impresora serial nativa de MAME y el lanzador
scripts/as3k_print_run.py, que configura 57600 baudios,
conserva el autoboot del usuario, crea sesiones únicas,
captura los PCL auténticos y los entrega al conversor
scripts/as3k_print_to_host.py, adaptado del AS2K estable.

Prueba funcional: Writer original, tecla física Print; 55 bytes
HP/PCL exactos, texto r8proof, terminación de página, MAME exit 0,
receptor exit 0. CUPS AlphaSmart_PDF-14 completado.
PDF de una página carta, texto r8proof comprobado por renderizado.
El PDF del filtro CUPS emplea CID sin ToUnicode fiable, por lo
que la extracción mediante pdftotext no es criterio de fidelidad.
No se utilizó la memoria Writer para generar el contenido.

Regresiones del binario final: ./alphasma3k -validate PASS;
USB R10 descriptor, enumeración, Get 47 B, concurrencia y UNLINK
PASS (anfitrión y emulador exit 0), carpeta
work/r11_print_regression_irq_restored_20261109.
PS/2 Send PASS: r8proof r11 seguido de LF, decoder Set-2
independiente idéntico tras normalizar Enter CR/LF.
Se restauró la señal de presencia de host previa que una
modificación anterior había retirado. Sin ROM modificada,
emuladores alternativos ni commit/push.

Impresión R11: CLOSED/PASS.
R11 global: OPEN (ADB e IrDA).
R10: CLOSED/PASS.
